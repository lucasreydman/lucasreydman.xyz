# lucasreydman.xyz

Personal site for Lucas Reydman, live at [lucasreydman.xyz](https://lucasreydman.xyz). One page, a dark scroll-driven composition: Next.js 16, React 19, Tailwind v4, Motion, and three.js for the metal.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run lint
```

Copy lives in `content/`. Architecture, design rules and the screenshot workflow are in [AGENTS.md](AGENTS.md); read it before changing a scene.

Deployed on Vercel from `main`.
